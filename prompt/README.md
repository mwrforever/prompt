## 使用纪律

1. **单技能强制加载**：开工前必须实际加载该文件指定的唯一技能正文；未实际加载不得开工——纸面说明 / 简短转述 / 声称已加载均无效；全程禁加载第二个插件技能。
2. **串联顺序**：方向 → 施工 → 打磨 → 终验，顺序不可逆；施工无蓝图一律退回方向裁决；打磨与施工产物均须经终验通过方可交付。
