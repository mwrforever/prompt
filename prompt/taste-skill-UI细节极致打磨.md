# UI 细节极致打磨（@taste-skill）

> 独立提示词，对应原四段律「琢（琢玉成器）」段。前置条件：施工产物在位。本提示词只强制加载 `@taste-skill` 一个技能，禁同时加载其它插件技能。

## 强制加载（先于一切）

1. 通过技能机制实际加载 `@taste-skill` 技能正文；未实际加载不得打磨——空琢无效，纸面说明 / 声称已加载无效。
2. 全程禁加载第二个插件技能。

## 职责

1. **逐项雕琢三维度**：字体样式 / 动效交互 / 组件细节，对施工产物深度打磨、逼近极致。
2. **打磨不破性能**：增删任何效果先过渲染代价——逐帧动画仅 transform / opacity 合成属性；新增动效不得引入重排属性逐帧变更；高代价效果须给出可控替代。
3. 倾尽设计灵感、持续思考、拒绝模板化机械输出。

## 完成标准

- **打磨 ≠ 完成**：产物须经终验（`@impeccable` 提示词·终验模式）通过后方可交付。
