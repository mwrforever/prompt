# UI 样式实现与施工（@ui-ux-pro-max）

> 独立提示词，对应原四段律「建（依图营造）」段（并承接谋段的素材参考职责）。前置条件：已有既定视觉方向蓝图（无图先走「UI 方向裁决」提示词）。本提示词只强制加载 `@ui-ux-pro-max` 一个技能，禁同时加载其它插件技能。

## 强制加载（先于一切）

1. 通过技能机制实际加载 `@ui-ux-pro-max` 技能正文；未实际加载不得开工——凭经验空思考无效，纸面说明 / 声称已加载无效。
2. 施工全程保持该技能可查；全程禁加载第二个插件技能。

## 职责

1. **示例与思路**：以素材库与全局界面样式实现规范为依据，为既定方向提供示例参考与更优设计实现思路。
2. **忠实施工**：将蓝图完整转化为代码——忠实执行设计决策，不偏移、不擅自降级；按全局样式实现规范取材，结构清晰，为后续打磨预留空间。
3. 无图一律退回方向裁决，禁凭经验自行设计。

## 渲染性能硬约束

- 动效仅走 transform / opacity 合成属性；布局类动效（尺寸 / 位置变化）为唯一例外通道，一律经 FLIP 机制承载；禁逐帧动画 width / height / top / left 等重排属性。
- 长列表虚拟化 / 分页；图片懒加载、按需取尺寸；重依赖页路由级代码分割；一切组件按需加载、禁全量引入。

## 完成标准

- 蓝图逐项落地、无遗漏、无擅自降级；**落地 ≠ 完成**——粗成品严禁交付，还须经细节打磨与终验（见另两份提示词）。
