# 任务交接文档 (Session Handoff)

> ⚠ **交接声明（务必先读）**：本文档由 `session-handoff` 技能生成，是新会话续接任务的**唯一事实来源**，内容仅来自当前会话的事实，自包含、不引用其他进度文档或历史会话记录。
> 「第 3 节 未完成」中的全部任务必须在【新会话】执行；生成本文档的会话已交接封存，不再实现任何任务。
> 新会话续接前必须完整读取本文档、以本文档为准，禁止凭空推测进度或重复已完成的工作。
> 代码与文件变更明细不在本文档记录，新会话用 `git diff` / `git log` 自行查看。

## 元信息 (Meta)
- workspace_dir: <任务所属项目的真实绝对路径，不是临时会话目录>
- saved_at: <ISO8601 时间，如 2026-08-24T15:30:00+08:00>
- 生成方式: <rewrite（本次新建）或 update（更新本会话的文档）>
- 版本控制提交号: <如 git commit hash，便于新会话检测环境漂移；无版本控制填 N/A>
- 交接状态: 已交接（本会话封存，未完成部分须在新会话执行）
- 任务一句话描述: <本次任务要达成的目标>

## 1. 会话 Todo 追踪 (Session Todo)
> 当前会话待办追踪列表在封存时刻的原样快照；只列条目，不加说明。
- [x] <已完成条目>
- [ ] <未完成条目>

## 2. 已完成 (Completed) — 只做精简标记
> 每条一行、只留一句话结论，让新会话知道哪些不用再做；禁止展开过程描述。
- [x] <事项名>: <一句话结果>

## 3. 未完成 (Pending) — 精简且可执行（全部须在新会话执行）
> 每个未完成任务按 3.1 子结构填写，每行一句话，写到可立即执行即可，不展开背景长文。

### 3.1 <未完成任务标题>
- 目标与当前状态: <要达成什么 + 已做到哪一步（具体到文件/产物/已通过的环节）>
- 已锁定决策/阻塞风险: <新会话不得推翻的决策、选型、契约，以及卡点与坑；无则删>
- **下一步具体动作**: <可立即执行的最小一步，含命令/位置；写"在 X 的 Y 处做 Z"，不写"继续做">
- 验证方式: <操作 + 预期结果>

## 4. 环境与全局约定 (Environment & Conventions)
> 精简描述，每行一句话；无对应内容的行填"无"。
- 运行时/工具版本: <涉及的语言/运行时/工具版本；无则填"无需">
- 关键配置: <必须设置的环境变量与配置文件路径；无则填"无">
- 构建/启动命令: <从零复现环境的命令序列；无则填"无需">
- 全局约定: <跨会话必须遵循的目录结构/命名/接口契约/用户硬性约束；无则填"无">
