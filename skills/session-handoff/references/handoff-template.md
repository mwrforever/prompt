# 任务交接文档 (Session Handoff)

> ⚠ **交接声明（务必先读）**：本文档由 `session-handoff` 技能生成，是把当前会话任务移交给【新会话】的**唯一事实来源**。
> 本文档「第 2 节 进行中 / 未完成」中的**全部任务必须在【新会话】中执行**；
> 生成本文档的会话已完成交接并封存，**不再实现任何未完成任务**。
> 新会话续接时必须先完整读取本文档，以本文档为准，禁止凭空推测进度或重复已完成的工作。

## 元信息 (Meta)
- workspace_dir: <任务所属项目的真实绝对路径，不是临时会话目录>
- saved_at: <ISO8601 时间，例如 2026-08-24T15:30:00+08:00>
- 版本控制提交号: <当前版本控制提交号，如 git 的 commit hash，便于检测漂移；不使用版本控制则填 N/A>
- 交接状态: 已交接（本会话封存，未完成部分须在新会话执行）
- 任务一句话描述: <本次任务要达成的目标，一句话>

## 2. 进行中 / 未完成 (Pending) — 重点详述（全部须在新会话执行）

> 至少包含：目标、当前状态、涉及文件/产物、已锁定决策、阻塞点、下一步具体动作、验证方式。
